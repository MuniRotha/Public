# Simple Interest Calculator

A small Bash script that calculates simple interest from user input.

## What it does

`simple-interest.sh` asks for three values and prints the interest earned:

- **Principal**: the starting amount
- **Rate of interest**: the yearly rate, as a percentage
- **Time period**: the number of years

The formula used is:

    Simple Interest = (Principal x Rate x Time) / 100

## How to run

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

## Example

```
Enter the principal amount: 1000
Enter the rate of interest (% per year): 5
Enter the time period (in years): 2
Simple interest:  100.00
```
